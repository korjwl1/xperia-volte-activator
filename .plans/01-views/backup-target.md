# view: BackupTarget (④ 백업 경로/용량)

status: implemented (mock)

## 목적/진입
BackupSelect 다음. 백업 저장 위치 지정 + 예상 용량 검증.

## 상태 필드
- 경로 입력 + [폴더 선택...] (M2 실장 전까지 mock 경로/타이핑 허용)
- 용량 카드: 그룹별/합계 예상 vs 대상 드스크 여유 (부족 시 경고)
- 보존 정책 안내: "복구 승인 전까지 백업 보존" (§6-1)

## 인터랙션 → 계약 매핑
| 요소 | 동작 | 계약 |
|---|---|---|
| [폴더 선택...] | 네이티브 다이얼로그 | `dialog:open`(Tauri plugin, M2) — mock: 기본 경로 제안 |
| 경로 타이핑 | 유효성 표시 | (프론트) |
| [백업 시작] | ⑤로 (RunProgress가 백업 단계부터 실행) | `backup_estimate` 갱신 |
| [뒤로] | ③ 복귀 | — |

## 특수 규칙
- 한글/공백 경로 허용 표시(§12.5) — mock 경로에 한글 폴더명 포함시켜 검증

## 비주얼 (desktop-ui 스킬)
경로 카드(FolderOpen 아이콘 인셋 인풋) / 용량 = **스택 컬러 바 + 그룹 범례** + 사용률 게이지(여유 충분=success/부족=destructive).
