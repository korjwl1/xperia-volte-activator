# view: BackupSelect (③ 백업 항목 선택)

status: implemented (mock)

## 목적/진입
초기화 루트가 있는 계획에서만 노출. 분류 배지(§6-4)와 함께 체크박스 그룹 제공. 기본 전체 체크.

## 상태 필드
- 그룹 5종: [시스템 설정] [앱 (설치 목록+데이터)] [본체 저장소 /sdcard] [숨은 영역 Android/data] [SMS/통화기록]
- 앱 리스트: AppItem[] — 배지 ✅완전/⚠️불완전/❌불가 + 비고(계정동기화/기기바인딩/앱내백업)
- "구글 백업: N일 전" 배지 (`dumpsys backup` 근거)
- 그룹별 예상 용량/항목 수

## 인터랙션 → 계약 매핑
| 요소 | 동작 | 계약 |
|---|---|---|
| 그룹 전체 체크/해제 | 하위 항목 일괄 | (프론트 로직) |
| 개별 체크 | 백업 대상 Set 갱신 | (프론트 로직) |
| [백업 건너뛰기] | 이중 경고(모든 데이터 손실 감수 2회 확인) 후 ⑤로 | (프론트 로직, 세션에 스킵 기록) |
| [다음] | ④로 | `backup_scan_items` 결과 사용 |
| [뒤로] | ② 복귀 | — |

## 특수 규칙
- ❌(불가) 항목은 체크박스 비활성 + "수동 재설정 가이드" 툴팁
- Android/data 그룹은 "MTP로 안 보이는 영역" 안내 문구
