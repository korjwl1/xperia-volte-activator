# 설정 · 기록 관리 (SettingsView)

2026-10-08 사용자 요청. 처음 화면(기기 상태) 오른쪽 위 [설정]으로 연다. 전체 화면(사이드바 없음), 하단 [처음 화면] / [선택 삭제].

- 목록(`records_list`): VoLTE 패치 기록(패치 전 모뎀 설정 사본 포함), 마지막 백업 위치(폴더 기억만 — 백업 파일은 지우지 않음), 진행 기록(journal), 순정 부트 이미지 캐시, 기록 없는 모뎀 설정 사본. 종류별 묶음·전체 선택, 줄마다 체크, 날짜·용량.
- 여러 개를 골라 [선택 삭제] → 확인 창(고른 목록, 패치 기록이면 "되돌릴 수 없음" 경고) → `records_delete`.
- 부트 기록 이력(flash-history)·이미지 대조 기록은 리락 안전 확인의 근거라 목록에 넣지 않는다.
