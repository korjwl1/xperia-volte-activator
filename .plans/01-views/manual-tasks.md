# view: ManualTasks — 수동 그리드

status: implemented (2026-10-08)

백업·복구·언락·리락·루팅·언루팅·VoLTE 패치·통신 확인·루팅 매니저 변경·루팅 모듈 설치를 3열 그리드로 표시한다. MANUAL_TASKS/manualTaskProblem 조건을 계획과 공유하고 최신 deviceList 조회 성공 후 chooseManualTask한다.

백업/복구는 Android 연결, 언락은 지원 파티션+locked, 리락은 지원 파티션+unlocked, 루팅은 unlocked+비루팅, 언루팅/패치/매니저 변경은 지원 unlocked+rooted, 모듈은 unlocked+rooted, 통신 확인은 인식된 SIM이 필요하다. 불충족은 비활성 이유를 표시한다.

백업→step2+기록 확인, 통신 확인→communication, 매니저/모듈→root-tools의 해당 section, 나머지→작업별 warning. 패치는 USIM을 거친다. 이전→mode-select. 완료 뒤 입력을 정리하고 목록으로 돌아간다.

비주얼: lucide 아이콘/설명의 MD3 카드·비활성 사유·pane 스크롤. 직접 쓰기 호출 없음.
- 2026-10-08 (사용자 결정): 수동 언루팅은 초기화가 없으므로 백업 단계를 넣지 않는다(준비 → 언루팅). 루팅·리락 계획은 그대로다.
- 2026-10-08 (사용자 요청): 작업을 분류(`MANUAL_TASK_GROUPS`)로 묶어 표시한다 — 백업·복구 / 부트로더(언락·리락) / 루팅(루팅·언루팅·매니저 변경·모듈 설치) / VoLTE(패치). 분류마다 제목·한 줄 설명 아래 4열 카드. **통신 확인은 수동 작업 목록에서 제거**했다(통신 확인 화면 자체와 이전 진행 기록의 `verify` 작업 해석은 유지).
- 2026-10-08: 실전 기능이 꺼진 작업(리락·루팅 매니저 변경·모듈 설치)은 카드에서 "실기기 검증 전이라 아직 사용할 수 없습니다"로 비활성. 화면 표기는 "복원"으로 통일.
- 2026-10-08 (사용자 결정): VoLTE 분류에 "VoLTE 되돌리기"(`volte-rollback`) 추가. 이 폰의 기록에 패치 전 사본이 없으면 "되돌릴 VoLTE 패치 기록이 없습니다", 실전 스위치(`REAL_STEPS.volteRollback`)가 꺼져 있으면 "실기기 검증 전" 사유로 비활성. 루팅된 언락 기기 필요. 계획은 `efs-rollback` 한 단계(DIAG 전환 → 슬롯별 최신 사본을 최신 패치부터 복원 → OS 재부팅·재연결).
- 2026-10-08 (사용자 결정): 루팅 매니저 변경은 루팅 도구 화면이 아니라 일반 수동 계획이다 — 순정 이미지 준비 → 기존 루팅 해제(모듈·매니저 데이터 전부 삭제) → 다른 엔진으로 루팅. 대상 엔진 기본값은 지금 엔진의 반대(기기 상태의 rootEngine), 지금 엔진은 선택 불가. 모듈·설정 이전은 하지 않는다. 카드는 root·fastboot·rootTools 실전 스위치가 모두 켜져야 쓸 수 있다.
- 2026-10-08: 되돌린 패치는 기록에 `rolledBackAt`을 남기고 되돌리기 대상에서 뺀다 — 되돌릴 패치가 없으면 카드가 "되돌릴 VoLTE 패치 기록이 없습니다"로 비활성. 설정의 기록 목록에는 "· 되돌림"으로 표시.
