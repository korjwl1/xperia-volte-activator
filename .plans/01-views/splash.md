# 시작 스플래시 (SplashScreen)

2026-10-08 사용자 승인 시안(`../output/splash-preview/preview.html`, Codex 작성)을 앱에 옮겼다.

- 목적: 앱 첫 실행 때 첫 기기 조회가 끝날 때까지 빈 화면을 가린다. 앱 실행당 한 번만 표시한다.
- 그림: `src/lib/splash/draw.ts`(시안 Canvas 코드 이식, 960×600 논리 좌표), 폰 이미지 `static/splash/xperia-phone.png`(GPT 생성 원본 RGBA). 거의 검은 남색 배경·청록/주황 궤도·XPERIA/VoLTE Activator·"시작 준비 중"과 불확정 신호 파형. 3.8초 등장 후 3.2초 주기 대기 모션.
- 닫힘: `wizard.startupReady`(기기 상태 화면의 첫 조회가 성공·실패와 무관하게 끝남) 또는 첫 화면이 기기 화면이 아님 또는 15초 경과 → 0.45초 페이드. 3.8초는 연출 길이이며 최소 대기 시간이 아니다. 실제 준비와 무관한 진행률·성공 표시는 없다.
- 움직임 줄이기(`prefers-reduced-motion`): 등장이 끝난 정지 화면 한 장만 그리고, 설정이 바뀌면 다시 적용한다. 창 크기 변경에 맞춰 기기 픽셀 비율로 다시 맞춘다. 언마운트 때 requestAnimationFrame·리스너를 정리한다.
- 이미지 불러오기 실패: 폰 없이 나머지를 그린다(닫힘 조건은 그대로).
- 빈 창 번쩍임 방지: `app.html`의 html 배경과 Tauri 창 `backgroundColor`를 스플래시 배경색(#080b12)으로 칠한다. 앱 화면은 자체 배경으로 덮으므로 시스템 테마 정책에는 영향 없다.
- 시안의 설명문·다시 재생·일시 정지·움직임 줄이기 버튼은 넣지 않았다.
