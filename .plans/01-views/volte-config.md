# view: VolteConfig (1단계 — 사전 옵션 선택)

status: implemented

## 목적/진입
경고 페이지 동의 후. VoLTE 패치 대상(SIM 슬롯별 통신사)과 펌웨어 버전을 고른다.
여기서 고른 내용과 기기 상태를 종합해 2단계(작업 옵션 선택)의 실행 순서가 정해진다.

## VoLTE 설정 (카드 1)
- SIM 카드(슬롯별): 슬롯 번호, 물리/eSIM 배지, 현재 통신사(또는 SIM 상태)
  - 카드 안 선택지: [SKT] [KT] [LG U+] [패치 안 함] → `wizard.volteConfig.sims[].carrier` (null = 패치 안 함)
  - LG U+ 선택 시 1 V/5 V(XQ-DQ*/XQ-DE*)는 내부적으로 LGU_V 전용 프리셋 사용 (UI에는 LG U+로 표시)
- 프로파일 모드 선택 없음 (사용자 결정 2026-10-02): EFS 프리셋은 원본 CLI가 실제로 사용해 온 단일 프리셋(SonyEFS, balance)만 사용

## 펌웨어 설정 (카드 2)
- `firmware_versions`로 서버 버전 조회(기기당 1회) — 설치된 버전 이상만 표시, 다운그레이드 미제공
- 첫 줄은 항상 설치된 버전("현재 설치된 버전" 배지), 서버의 더 새 버전은 "새 버전" 배지
- 선택 → `wizard.volteConfig.firmware` (설치된 버전 선택 = null = 업데이트 안 함)
- 조회 중 인디케이터 / 실패 / 미지원 기종 / 최신 버전 안내 문구

## 부트로더만 작업 (사용자 지시 2026-10-03)

- 펌웨어 설정 카드 아래 "부트로더만 작업" 카드: [언락만 진행하기] / [리락만 진행하기]
- 활성 조건: 모든 SIM이 "패치 안 함" + 펌웨어가 현재 버전(업데이트 없음). 언락만은 잠긴 기기, 리락만은 언락된 기기에서만
  (부트로더 상태 확인 불가면 둘 다 비활성 + 사유 표시). 같은 버튼을 다시 누르면 선택 해제
- 통신사나 새 펌웨어 버전을 고르면 선택이 자동 해제 — 패치·업데이트와 함께 진행하지 않음
- 선택 시 1단계 [다음] 활성 (wizard.hasAnyTask)
- 패치 제거 기능은 넣지 않음: EFS 패치가 순정 파일을 덮어쓰는 구조라 원래 값 없이는 정확히 되돌릴 수 없음 (사용자 결정 2026-10-03)

- 기종별 참고 사항은 wizard.workflow(data/devices.ts deviceWorkflow)에서 생성한다. IV의 KT·LG U+ 실패/성공 보고는 해당 통신사 선택 때만, III·PRO-I 후속 앱 설정은 리락 선택 때만, II 외부 PDC는 EFS 선택 때만 표시한다. 부트 파티션은 모델 표로 선택하며 SIM 감지나 최신 펌웨어 여부로 작업을 바꾸지 않는다.
- II/IV는 일반 EFS 경로를 허용한다. PDC·모뎀 교체·Pixel IMS 설치를 새로 구현하지 않으며, 별도 상세 글 598708/591068의 404를 확인하고 공개 사용자 보고/작성자 댓글로 안내 출처를 교체했다.
- 리락만 선택해도 같은 펌웨어의 순정 이미지 복원을 포함하며, VoLTE 유지 보장 문구를 제거했다. 표 밖 모델은 지원 미확인으로 표시한다.
2026-10-06 SIM 유형 배지: physical=물리, esim=eSIM, unknown=유형 미확인. 구독 정보가 없는 슬롯을 eSIM으로 표시하지 않는다. 비주얼: 기존 outline 배지 유지.
