# view: Finish (점검 및 마무리)

status: implemented

실행이 끝나면 작업 결과와 통신 확인 결과를 구분한다.

- EFS 성공 기준은 선택한 대상 파일·NV의 리드백 일치다. SIM 유무·현재 통신망은 패치 대상을 바꾸거나 파일 작업 성공을 부정하지 않는다.
- 확인 결과 카드: 파일·NV 기록 검증(verify 단계 완료), 셀룰러 IMS 음성 등록(imsVerified), 실제 발신·수신(callVerified, 사용자 확인).
- 파일 검증 후 등록을 생략하면 “패치 완료 · 통신 미확인”, IMS만 확인하면 “패치 완료 · 통화 미확인”. 미확인은 amber 아이콘·톤으로 표시한다.
- 문자·MMS·5G 데이터·로밍은 별도 확인. SIM 장착·교체 시 프로파일 재적용으로 재패치가 필요할 수 있음을 안내한다.
- 백업 보관·삭제 계약 유지. 비주얼: 기존 MD3 카드·pane 스크롤·의미색 토큰.
