## 부트로더만 작업 계획 (mock/plan.ts bootloaderOnlyPlan)

- 언락만: 사전 준비(언락 조건 필요 시 · 언락 코드) → 백업(선택) → 부트로더 언락 → 기본 설정(USB 디버깅) → 복구(선택)
- 리락만: 사전 준비(언루팅용 순정 펌웨어, 루팅 안 됨이 확인되면 생략) → 백업(선택) → 언루팅(루팅 여부 미확인 포함) → 부트로더 리락 → 기본 설정 → 복구(선택)
- 루팅 탭: 옵션 없이 안내 문구만. 백업·복구는 초기화가 있으므로 기본 선택
- 패치 흐름의 리락 뒤에도 "기본 설정(USB 디버깅)" 단계 추가 — 초기화 후 최종 확인·복구에 adb 연결 필요

- 이미 루팅된 기기의 언루팅(리락 포함)에도 사전 준비에 순정 펌웨어 준비 포함
- VoLTE 패치를 하면 부트로더 판별 여부와 관계없이 최종 확인(IMS) 포함
- 실행 전: 백업을 선택했는데 백업 위치 여유 공간이 0이거나 확인 중·확인 실패면 실행하지 않음(데스크톱 앱)

- 업데이트 설명: 패치 유지 = 모뎀·DSP·TA·사용자 데이터 제외 / 재패치 = 모뎀·DSP 포함(TA·사용자 데이터 제외)
- VoLTE 적용은 슬롯별 두 번 주입, 적용 확인은 전수 리드백·해시 비교. "VoLTE 활성화 설정"은 통신사 서비스 검증이 아님을 설명에 명시
- 언루팅·리락이 있으면 그 앞에 "통신 확인"(ims-precheck: IMS 등록 자동 확인 + 실제 발신·수신 체크, 실패 시 [다시 패치])
- 최종 확인은 리락·복구까지 끝난 뒤(복구 → 최종 확인 순서)
- 실행 순서 아래: 패치 대상 슬롯의 SIM 문제(미삽입·PIN 잠김·통신사 확인 불가)를 고정 표시 —
  선택한 통신사·슬롯은 SIM 유무나 감지된 통신망으로 바꾸지 않는다. SIM 없이도 EFS/NV 기록·리드백을 수행하며 통신 확인은 별도다. 언루팅 전 통신 확인도 생략 가능하며 리락 전 현재 펌웨어·추출 이미지·양 슬롯 복원 조건은 별도로 확인한다.
