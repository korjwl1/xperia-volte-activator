# view: PlanReview (② 작업 계획 확인)

status: implemented (mock)

## 목적/진입
DeviceStatus에서 [작업 시작] 후. 현재 상태 기반 계획(§3-2 매트릭스)을 프로파일+토글로 조정.
초기화 루트가 있으면 다음 단계(③ 백업)로 강제 이동.

## 상태 필드
- 프로파일 카드 3종: 순정 복귀(기본)/루팅 유지/언루팅만 — 초기화 횟수 배지(2회/1회/1회)
- 단계 리스트: PlanStep[] — 필수(자물쇠 아이콘, 끌 수 없음) vs 선택(토글), 위험 배지(⚠ 초기화/위험), 예상시간
- 의존성 경고 배너: 리락⟹언루팅 강제(언루팅 끄면 리락도 자동 off + 경고)

## 인터랙션 → 계약 매핑
| 요소 | 동작 | 계약 |
|---|---|---|
| 프로파일 선택 | 기본 토글 세트 적용 후 재계산 | (프론트 로직, plan.md §3-3) |
| 선택 토글 | 의존성 규칙 검사 후 스토어 갱신 | (프론트 로직) |
| [이 계획으로 진행] | 계획 확정 → 초기화 루트 있으면 ③, 없으면 ⑤ | `plan_generate` 확정 |
| [뒤로] | ① 복귀 (선택 유지) | — |
| EFS 프리셋 미설정 시 | 경고 표시 + 설정 유도 링크 | `env_check` 결과 재사용 |

## 특수 규칙 (§3-3)
- 파괴 단계(언락/리락) 활성 = 완결 백업 전제 → 백업 스킵 선택 시 이중 경고가 ③에서 발생
- 리락 켜기 시 언루팅 강제 ON + 순정 이미지 근거 없으면 리락 게이트 표시(M4+ 실장)

## 비주얼 (desktop-ui 스킬)
프로파일 카드(아이콘 타일 + 선택 ring + 초기화 배지) / 단계 = **세로 타임라인**(위험도 색 도트 + 연결선, destructive/warning/primary) / 의존성 배너 = warning 톤.
