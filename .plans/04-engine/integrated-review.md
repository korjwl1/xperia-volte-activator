# 병합된 엔진 코드 리뷰 — 2026-10-04

status: implemented (코드 리뷰·가짜 I/O 테스트 완료, 이번 작업의 실기기 테스트 없음)

대상은 세 브랜치가 병합된 main(cb7846c)이다. 이전 전체 코드 리뷰는 [code-review.md](code-review.md), 이번 검토는 루팅·언루팅·fastboot·펌웨어 입력과 Wizard의 통합 실패 경로에 집중했다. EFS 작업 트리와 브랜치는 수정하지 않았다.

## 발견한 문제와 수정

| 수동 펌웨어 검사 후 SIN 파일 자체를 패치·플래시에 전달 | SIN의 raw IMG를 내용 해시 이름으로 캐시에 추출. update.xml 지문과 실제 IMG 경로를 공통 타입으로 반환. SIN 후보 중복·메타데이터 없음은 거부 |

| 연결 기기가 교체되면 fastboot가 다른 기기에 기록 가능 | 언락·기록·재부팅 전에 expectedSerial과 fastboot serialno 대조. 값 없음·불일치는 명령 전 차단 |

| 이벤트 등록 중 취소 뒤에도 다음 쓰기 실행, 늦은 root_check가 새 실행 완료 | 비동기 경계마다 실행 세대 확인, 늦은 등록 해제. 실제 재부팅 응답 실패도 failed로 정지 |
| 비동기 interval 폴링 중복, 예외·멈춘 질의가 제한 시간 무효화 | 순수 waitUntil 서비스: 질의 하나씩 실행, 독립 제한 시간·취소 감시, 늦은 응답 무시 |

## 실기기로 테스트하지 않은 부분·남은 한계

이번 작업에서는 앱의 실제 기기 연결, USB 조회, ADB/fastboot 명령, 다운로드 서버 접근, 기기 쓰기 또는 부팅을 실행하지 않았다. 문서의 기존 실측 절차는 과거 자료이며 이번 구현의 실기기 검증 결과가 아니다.

- Sony 기종별 ADB/fastboot 식별값 일치 여부, WinUSB 드라이버, USB 전환·재연결·타임아웃 동작. TCP ADB 식별자가 실제 fastboot serial과 다르면 안전하게 차단하며 매핑을 추정하지 않는다.
- 실제 SIN/update.xml 변형, firmware 서버 및 최신 Magisk APK 형식, 스크립트 성공/실패, 설치·권한 승인·부팅·언루팅 효과.
- Android 부트 헤더 전체·파티션 적합성·실제 플래시 리드백·슬롯 부팅 가능성을 인증하지 않는다. 매직·크기·해시는 기본 입력/전송 일관성 검사다.
- SIN 서명·APK 서명·공식 원본과의 암호학적 출처 인증, AVB 키·rollback index·vbmeta 및 전체 부트 체인 검증은 미구현. 펌웨어 지문 일치나 전송 이력은 이를 대신하지 않는다. 이 때문에 리락은 all-features 빌드에서도 차단한다.
- 한 슬롯 기록 후 다른 슬롯 실패 시 롤백을 자동 수행하지 않는다. 이력에 미완료 상태를 남기고 중단한다.
- 프런트 취소는 이미 실행 중인 기기 명령을 강제 취소하지 않는다. 다음 단계와 늦은 응답을 차단하며 기존 I/O가 끝날 때까지 변경 실행권을 유지한다.
- EFS/newflasher 실전 구현은 별도 작업이다. 현재 기본 REAL_STEPS 및 쓰기 Cargo feature는 비활성 상태를 유지한다.

실제 연결에서 이 제한을 확인하고 출처·AVB·전체 체인 증명을 구현한 뒤에만 리락 차단 해제를 검토한다.
